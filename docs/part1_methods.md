# 两条正常建模基线

## 正常模板差分

ECC估计模板坐标到测试坐标的平移/旋转矩阵，逆向采样得到与模板对齐的测试图。估计使用平滑灰度图；差分使用灰度绝对差再做11×11高斯平滑。亮前景分割的Otsu阈值只来自正常模板；取最大外轮廓并填充，模板与测试前景取并集，按正常物体框最长边10%外扩以保留边缘。该分割假设仅适合单个亮腰果/暗背景，不能直接用于六个类别。

配准边界用有效采样mask排除，局部窗口不能接触无效区域。连续热图映回原测试坐标后才与官方GT比较。报告统一128设置下，ROI之外与未覆盖位置的分数为0，全图评价不忽略被掩膜排除的缺陷。

模板单图CLI采用ROI内最高1%均值的原尺寸教学分数；统一对照采用128全图最高1%均值。因此两个入口必须分别正常校准，不能交叉使用阈值。SSIM保留为教学对照，不参与当前报告主方法。

## 卷积自编码器

RGB图直接resize到128×128、转换到0–1浮点、HWC转CHW。编码器的三层stride=2卷积产生16、32、64通道，空间128→64→32→16。解码器三层转置卷积恢复到128，Sigmoid限定输出0–1。

模型只在407张正常图上训练10轮，用Adam(lr=0.001)优化RGB MSE。40张独立正常校准图不参与训练；不使用异常标签选epoch。推理误差为每像素RGB三个通道绝对误差的平均，整图取最高1%像素均值。图像和像素阈值都需要重新从该模型的正常误差校准。

正常训练数据预算不同：AE使用407张，模板差分使用1张。当前AE不是few-shot训练模型，也不是预训练基础模型。

## 通用代码

- `common/images.py`：RGB读取、缩放、灰度浮点、CHW张量、无窗口绘图后端。
- `common/visa.py`：官方1cls CSV与二值GT，正常图全零mask。
- `common/scoring.py`：最高1%均值、向上取正常分位数、3×3开闭运算。
- `common/metrics.py`：图像AUROC/AP/混淆矩阵/FPR/FNR、像素AUROC/AP、AUPRO。

AUPRO利用区域逆面积像素权重，使每个8连通GT区域对PRO贡献相同。负像素等权形成全图FPR，在0.3处线性插值截断并除以0.3。正常图也参与背景像素统计。

## 校准与局限

图像阈值为正常分数95%分位数；像素阈值为正常像素99.5%分位数，均向上选观测值，判决采用严格大于。分位数估计不保证新数据上的误报比例。合并像素的校准不能视为大量独立样本保证。

差分二值预测采用3×3开运算后闭运算；可能抹除小缺陷，所以教学CLI保存原始预测。AE128输出不做形态学，避免进一步移除小区域。连续指标不受这一步影响。

本阶段只完成cashew。尚需在最终协议中完成必需六类、纹理/结构缺陷的分类分析、至少20例错误原因标注、完整运行时间/内存测量。用户选择暂停Part1深入优化，下一阶段进入AnomalyDINO；这些未完成项仍保留在项目范围中。
