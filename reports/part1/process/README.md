# Part 1 过程图：从尝试到局限

这些是当时实际生成的历史输出，直接从本地归档恢复，未重新绘制或修改像素。保留过程比只保留最终对比更能解释方法选择。每张图的出处、校验和和讲解要点见 [manifest.json](manifest.json)。

## 先区分三个实验设置

- **阶段1–4**：原生1176×1274，参考正常000；正常测试001、异常测试000，可作连续步骤对照。
- **阶段5–7**：仍为原生分辨率，随机选择模板正常185；正常测试023、异常测试001。模板已经改变，不能把它们当作阶段4同一样例的受控提升。
- **阶段8和最终统一对照**：AE使用128×128。最终150张测试成绩在 [../results/metrics.csv](../results/metrics.csv)；阶段5的148张原尺寸分布仅解释历史实验。

阶段1–4中的“测试”指待检查的演示图；正常001实际来自官方训练划分，不是正式测试成绩。旁边JSON保留历史实验路径用于溯源，不作为当前命令入口。

图变干净不代表定位变准确；每个阶段应同时解释改善了什么、仍有什么局限。所有VisA展示图按仓库README的数据来源署名。

## PPT建议顺序

1. 正常图的未配准差分：提出“正常变化也会报警”。
2. 配准前后：解释位置对应关系，以及全局刚性配准的能力边界。
3. 平滑/SSIM尝试：展示方法不一定逐步变好。
4. 前景范围与筛背景效果：说明掩膜不能删掉边缘缺陷。
5. 正常阈值与测试分数分布：解释误报/漏检取舍。
6. 最高1%评分像素：把失败原因讲具体。
7. 自编码器损失与重建：引入学习式正常模型。
8. 最终统一指标与定位对照：总结基线局限，引出Part2。

每页选1–2张主图即可；原始二值mask、更多正常例和元数据可放备份页。完整记录不等于所有图都必须塞进主讲PPT。
